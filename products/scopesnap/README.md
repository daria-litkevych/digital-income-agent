# ScopeSnap prototype

A no-login browser utility for freelancers to estimate extra work and prepare a client-ready scope-change summary.

## Run

Open `app/index.html` in a modern browser. No build step, backend, account, external library or network request is required.

## Current prototype

- Original scope and requested change fields
- Additional hours, hourly rate and expenses
- EUR/USD/GBP currency selection
- Live total calculation
- Client-ready change summary
- Copy and print / save as PDF
- No persistent storage or data upload

## Important limits

This is a prototype hypothesis, not a validated or published product. It does not interpret contracts, determine whether work is legally out of scope, send messages, collect signatures or provide legal advice. The output is a commercial communication aid only.

## Next

Test with 5–8 freelancers, observe task completion, record objections and current alternatives, then decide whether to improve, reposition or stop.
