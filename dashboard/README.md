# Локальная панель проекта

Открой `index.html` локально в браузере. Панель не использует сервер, API, внешние библиотеки или учётные данные.

## Подключение данных
Скачай из `data/` файлы:
- `project_plan.json`
- `state.json`
- `market_research.json`

Открой `index.html` двойным щелчком и загрузи файлы через кнопку «Загрузить файлы».

## Приватность и ограничения
- Данные читаются локально в браузере и не отправляются на сервер.
- Панель не синхронизируется с GitHub автоматически.
- Экспорт плана скачивает локальную копию `project_plan.json`; чтобы сохранить изменения в репозитории, их нужно отдельно загрузить в GitHub.
- Не добавляй в проект секреты, пароли или access tokens.
- Не публикуй приватные данные через GitHub Pages.

Панель не исполняет AI-агентов и не запускает workflow. Она отображает данные, которые ты загрузила из репозитория.
